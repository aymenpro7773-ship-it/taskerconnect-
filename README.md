# نظام إدارة كروت الإنترنت (النسخة الموحدة الكاملة)

هذا الملف هو النسخة الموحدة والنهائية التي تجمع كل المزايا المتفق عليها في مكان واحد:
- إدارة الكروت والأكواد (إضافة، عرض، تعديل، حذف).
- ربط أرقام بديلة للزبائن (حتى 5 أرقام لكل زبون) مع إمكانية الاختيار من جهات الاتصال.
- الإرسال اليدوي عند انقطاع التغطية أو تأخر الشبكة دون ضياع الكروت.
- تشغيل مستمر في الخلفية وإعادة تشغيل تلقائية بعد إطفاء الجهاز، مع ضبط البطارية والظهور فوق التطبيقات للتنبيهات.
- دخول عبر البصمة / قفل الجهاز.
- مظهر ليلي ونهاري وتلقائي مع تصميم عصري عربي بالكامل.
- تقارير المبيعات (يومي، أسبوعي، شهري، إجمالي + تفصيل الفئات) وإضافة محفظة أخرى بجانب جيب.
